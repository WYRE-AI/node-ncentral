### Added

- Initial release of the N-able N-central REST API client.
- `NCentralClient` with typed resources: `system`, `serviceOrgs`, `customers`,
  `sites`, `orgUnits`, `devices`, `deviceFilters`, `scheduledTasks`,
  `accessGroups`, plus a raw `request()` escape hatch.
- Fully internal token lifecycle: lazy JWT authentication, proactive refresh
  60 s before access-token expiry, single re-authentication retry on 401.
- Token-bucket rate limiter (default 10 req/s) and automatic retry with
  exponential backoff on HTTP 429/5xx (honours `Retry-After`).
- Typed error hierarchy: `NCentralError`, `AuthenticationError`,
  `ForbiddenError`, `NotFoundError`, `ValidationError`, `RateLimitError`,
  `ServerError`.
- `PaginatedResponse<T>` envelope normalization and defensive `unwrap()`
  helper for `{ data: {...} }` single-entity envelopes.
- Zero runtime dependencies; dual CJS + ESM builds.
